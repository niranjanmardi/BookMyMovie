2. Aim

To optimize the BookMyMovie ticket booking application by applying route-level and component-level code splitting using React.lazy() and Suspense, optimizing image rendering with native lazy loading and async decoding, implementing an in-memory API caching layer, adding basic Progressive Web App (PWA) manifest and service worker support, making seat selection fully keyboard-accessible, and enforcing front-end security practices against XSS and sensitive data exposure.

3. Objectives Covered & Implementation Details

a) Lazy Loading for Movie Details and Seat-Selection Pages

  • Movie Details Page: Dynamically imported via const MovieDetailsPage = lazy(() => import('./pages/MovieDetailsPage')). The JavaScript chunk (6.09 kB) is only downloaded when a user clicks on a movie.
  • Seat-Selection Component: The 110-seat auditorium layout with tier calculations is code-split inside BookingPage.jsx via const SeatSelection = lazy(() => import('../components/SeatSelection')) with a custom Suspense spinner fallback.
  • A dedicated /seat-selection route was added for direct navigation.

b) Code Splitting for Route-Level Components

  • All major routes (HomePage, MoviesPage, MovieDetailsPage, BookingPage, SummaryPage, FoodOrderingPage, LoginPage, RegisterPage) are wrapped in React.lazy().
  • Enclosed in a central <Suspense fallback={<RouteLoadingFallback />}> boundary so users see an accessible loading spinner while chunks download.
  • Production build produces 12+ separate on-demand JS chunks, reducing initial page weight.

c) Movie Image & API Data Rendering Optimization

  • Optimized Image Component: Uses loading="lazy" to defer offscreen downloads and decoding="async" to prevent blocking the main thread.
  • Layout Shift Prevention (CLS): Forced aspect-ratio (2/3) with glowing skeleton shimmer during load.
  • Fallback Grace: Handles broken image links with an automatic cinema placeholder (🎬).
  • In-Memory API Cache: apiCache Map with a 5-minute Time-To-Live (TTL) caches repeated movie catalog searches and detail lookups.
  • Component Memoization: MovieCard and SearchBar are wrapped in React.memo to eliminate unnecessary re-renders.

d) Basic Progressive Web App (PWA) Support

  • Web App Manifest (public/manifest.json): Configured with app name, short name, start URL, theme color (#e50914), background color (#0b0f19), standalone display mode, and responsive SVG icons.
  • Service Worker (public/sw.js): Intercepts fetch requests with Cache-First strategy for static assets/posters and Network-First with cache fallback for HTML navigation, ensuring offline availability.
  • Registration: Automatically registered on window.load via src/serviceWorkerRegistration.js in main.jsx.
  • PWA Indicator: Added interactive PWA badge to the top navigation header.

e) Keyboard-Accessible Seat Selection & Accessible Buttons

  • Arrow Key Navigation: Users can navigate the 10×11 seat auditorium using ArrowUp, ArrowDown, ArrowLeft, ArrowRight, Home, and End.
  • Selection Toggling: Pressing Space or Enter selects or deselects the focused seat.
  • Screen Reader Accessibility: Each seat button has unique element IDs (id="seat-A1"), aria-pressed, aria-disabled, and descriptive spoken aria-label.
  • Live Announcements: aria-live="polite" region announces seat additions and subtotals in real time.
  • Focus Styling: Bright high-contrast yellow focus ring (outline: 3px solid #facc15) for keyboard navigation.

f) Front-End Security Practices

  • XSS Input Sanitization: sanitizeInput(text) utility regex-strips dangerous <script>, <iframe>, javascript: URLs, and inline event handlers across Search, Login, Register, and Booking Notes.
  • Content Security Policy (CSP): Added meta CSP tag in index.html restricting authorized script, style, and API domains.
  • Sensitive Data Masking: maskCardNumber() hides payment card digits showing only the last 4 (•••• •••• •••• 4242).
  • Input Length Boundaries: Enforced maxLength attributes across all input elements to prevent payload flooding.

9. Student Conclusion

In this experiment, I learned how to optimize a real-world React web application for performance, accessibility, and security. Using React.lazy() and Suspense reduced the initial bundle download by splitting routes into on-demand chunks. Image lazy loading and async decoding improved rendering responsiveness, while an in-memory API cache eliminated redundant HTTP fetches. Adding a Web App Manifest and Service Worker transformed the site into an installable PWA with offline capabilities. Implementing keyboard arrow navigation and ARIA attributes made the cinema auditorium accessible to disabled users, and input sanitization safeguarded the application against XSS attacks.
