2. Aim

To write and execute test cases for the BookMyMovie React application covering movie cards, movie details, seat selection, search and filtering, ticket price calculation, and booking confirmation.

3. Test Cases Written

a) Movie Card Component

  • Check if movie title, rating, and category are shown correctly
  • Check if poster image has correct alt text
  • Check if selected state shows the "Selected for Booking" badge
  • Check if clicking "Book Tickets" calls the onSelect function
  • Check keyboard accessibility (Enter and Space keys)
  • Check if null movie returns nothing (no crash)

b) Movie Search and Filtering

  • Check if search input shows the current query value
  • Check if typing triggers the onSearchChange callback
  • Check if the clear button appears and resets the search
  • Check if category filter (Tamil / Hollywood) works correctly
  • Check if genre filter shows the right movies
  • Check combined search + category filtering

c) Seat Selection and Removal

  • Check if clicking a seat adds it to selected list
  • Check if clicking the same seat again removes it (toggle)
  • Check if clicking the X button removes a seat from chips
  • Check if 110 seats are rendered (rows A to J)
  • Check that already booked seats are disabled

d) Ticket Price Calculation

  • Check seat category mapping: A-E = Regular (Rs.150), F-H = Premium (Rs.200), I-J = Recliner (Rs.300)
  • Check total price for empty seat list = 0
  • Check total for 1 Regular seat = Rs.150
  • Check total for 2 Premium seats = Rs.400
  • Check total for mixed seat types
  • Check that price updates when seats are added or removed

e) Booking Confirmation

  • Check that booking fails if movie, theatre, or seats are missing
  • Check that a booking ID is created in BMM-CBE-XXXXXX format
  • Check that booking is saved to localStorage
  • Check that same seat cannot be booked twice
  • Check that Redux state shows bookingConfirmed = true after confirm
  • Check that clearBooking resets all state to default

f) Booking Components (Admission Pass)

  • Check that admission pass shows movie name, theatre, date, time, and seats
  • Check that Confirm button is disabled when details are incomplete
  • Check that booking reference code appears after confirming
  • Check that "Book Another Movie" resets the booking
